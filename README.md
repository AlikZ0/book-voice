# BookVoice 1.2 — озвучивание PDF на iPhone без интернета

Нативное приложение на SwiftUI, PDFKit, Vision, AVFoundation, NaturalLanguage и MediaPlayer. Импортируйте PDF из приложения «Файлы», читайте или слушайте его системным голосом iOS. PDF и распознанный текст остаются на телефоне.

## Новое в 1.2

1. **Подсветка текущего предложения.** Слушатель отслеживает речь по `AVSpeechSynthesizerDelegate.willSpeakRangeOfSpeechString`. Текущее предложение отображается прямо над кнопками плеера. Для обычных PDF с текстовым слоем приложение пытается также выделить текст жёлтым непосредственно на странице. Если текст PDF содержит необычную разметку/переносы, выделение на самой странице может не совпасть или отсутствовать; строка с текущим предложением всё равно работает. У PDF-сканов без текстового слоя подсветка поверх картинки недоступна, но панель с распознанным предложением работает.
2. **Таймер сна.** Кнопка «Сон» во встроенном плеере: 5, 10, 15, 20, 30, 45, 60 или 90 минут; оставшееся время показывается в плеере. Можно отменить или выбрать новое время. По истечении времени озвучивание останавливается. Таймер рассчитан на продолжение фонового воспроизведения iOS; если iOS приостановит приложение, срабатывание до возвращения активности нельзя гарантировать.
3. **Плеер на экране блокировки / Пункт управления.** `MPNowPlayingInfoCenter` показывает название книги, номер страницы и обложку первой страницы PDF. `MPRemoteCommandCenter` обрабатывает воспроизведение, паузу, переход на предыдущую/следующую **страницу**. В проекте уже включён `UIBackgroundModes: audio`, а аудиосессия используется в режиме `.playback + .spokenAudio`.

**Принципиальное ограничение:** системный `AVSpeechSynthesizer` не предоставляет точную длительность/таймлайн книги, поэтому в системном плеере нет фиктивного ползунка перемотки по секундам. Для перехода используйте страницы.

## Остальные функции

- Локальная библиотека PDF и просмотр через PDFKit.
- Чтение системным голосом, выбор голоса и скорости.
- OCR страниц-изображений через Vision, без облачного сервера.
- Запоминание последней **страницы**, не точного слова.
- Автопереход на следующую страницу по окончании предыдущей.
- Без аналитики, регистрации и сетевых запросов.

В некоторых PDF текстовые колонки извлекаются в неожиданном порядке; качество OCR и доступность голосов зависят от версии iOS и установленных языковых пакетов. Системные голоса могут потребовать разового скачивания через настройки iOS, после чего озвучка работает локально.

## Обновление существующего репозитория

В этой версии сохранены предыдущие исправления `ReaderView` и делегата `BookSpeechPlayer` для Xcode 16.4. Чтобы **не остались старые файлы**, обновите перечисленные пути в вашем репозитории `book-voice`:

- Заменить `BookVoice/Services/BookSpeechPlayer.swift`.
- Заменить `BookVoice/Views/ReaderView.swift`.
- Создать `BookVoice/Services/SpeechDelegateProxy.swift`.
- Создать `BookVoice/Services/LockScreenPlayer.swift`.
- Создать `BookVoice/Views/SleepTimerSheet.swift`.
- Заменить `BookVoice/Views/SettingsView.swift` (строка версии).
- Обновить `project.yml` (номер версии).

Проще всего залить все файлы из полного ZIP в корень репозитория (с сохранением исходных путей). **Не создавайте второй вложенный каталог BookVoice** внутри уже существующего. В полном ZIP включён `.github/workflows/ios.yml`.

## Сборка через GitHub Actions без Mac

1. Загрузите содержимое папки проекта в корень репозитория GitHub.
2. Закоммитьте в ветку `main` и перейдите в **Actions → Build BookVoice for iPhone**.
3. После успешной сборки скачайте артефакт `BookVoice-unsigned-IPA`.
4. IPA **не подписан**: для установки на iPhone нужна подпись через SideStore / AltStore или ваш способ подписи.

Для запуска на Mac: `brew install xcodegen`, `xcodegen generate --spec project.yml`, затем откройте `BookVoice.xcodeproj` и настройте Signing & Capabilities.

## Проверки на реальном iPhone

- Откройте PDF с текстом, запустите речь. Сравните прочитанное предложение и жёлтое выделение на странице.
- Откройте PDF-скан. Убедитесь, что предложение видно в панели, даже если выделения на скане нет.
- Запустите таймер на 5 минут, заблокируйте iPhone. Проверьте остановку по времени.
- На экране блокировки и в Пункте управления проверьте обложку, заголовок, паузу/продолжение, предыдущую и следующую страницу.
- Проверьте переход на новую страницу при заблокированном экране и при переключении приложений.

## Статус сборки

Все Swift-файлы проверены синтаксическим парсером Swift 6.2 на Linux. Проверить полноценную компиляцию под iOS и поведение экрана блокировки можно только с iOS SDK/Xcode и физическим устройством; это **не было подтверждено** в текущем окружении. Если GitHub Actions выдаст ошибку, ориентируйтесь на **первую** строку `error:` в логе.
