# BookVoice 1.3 — локальное озвучивание PDF на iPhone

SwiftUI / PDFKit / AVFoundation / Vision / NaturalLanguage. Приложение импортирует PDF через «Файлы», читает текст и распознанные сканы, сохраняет страницу, умеет работать в фоне, показывает системный плеер и поддерживает таймер сна. Книга, распознанный текст и озвучка остаются на устройстве.

## Новое в 1.3: голоса и естественное чтение

- **Каталог голосов iOS:** отдельный экран со всеми голосами, которые система возвращает через `AVSpeechSynthesisVoice.speechVoices()`. Поиск, фильтры «Русский», «English», «Հայերեն» и «Все».
- **Качество голоса:** пометки «Premium», «Enhanced», «Стандартный». Автовыбор использует самый качественный из доступных голосов определённого языка (Premium > Enhanced > Standard). Предпочитается точная локаль при равном качестве.
- **Предпрослушивание:** кнопка ▶ возле каждого голоса читает короткую фразу; повторное нажатие останавливает пример. При чтении книги пример сначала ставит книгу на паузу. Кнопка обновления заново запрашивает голоса из iOS.
- **Более связное чтение:** текст разбивается по предложениям и абзацам, а не посреди произвольного слова; пауза после абзаца задаётся пользователем.
- **Настройка интонации:** высота голоса (0,8–1,2), скорость, пауза между абзацами (0–0,7 с). Есть пресеты «Обычно», «Книга», «Перед сном». Изменения применяются к следующему фрагменту.
- **Локальное хранение настроек:** выбор голоса, скорость, высота тона и паузы сохраняются через `UserDefaults`.

## Откуда берутся голоса

Список зависит от фактически установленных голосовых пакетов на iPhone. BookVoice не содержит сторонних голосовых моделей и не скачивает голоса автоматически. Чтобы добавить голоса, открой **Настройки iPhone → Универсальный доступ → Чтение и произношение / Устный контент → Голоса**; точное название раздела зависит от версии iOS. Можно выбрать улучшенный или премиальный пакет, если он доступен для языка. После установки вернись в BookVoice → «Голос и чтение» → «Выбрать голос» → «Обновить».

Системные голоса не гарантируют качество профессионального диктора: более ровные паузы и улучшенные голосовые пакеты уменьшают роботизированность, но «актёрское чтение» потребовало бы отдельной нейросетевой модели или внешнего TTS-сервиса. Голоса на армянском доступны не на каждой версии iOS.

## Обновление существующего репозитория

Для перехода с 1.2 замени/добавь только следующие файлы, сохраняя пути:

- `BookVoice/Services/BookSpeechPlayer.swift` — заменить
- `BookVoice/Views/SettingsView.swift` — заменить
- `BookVoice/Views/VoicePickerView.swift` — создать
- `project.yml` — заменить (версия 1.3.0)

Остальные файлы версии 1.2 должны остаться, включая `SpeechDelegateProxy.swift`, `LockScreenPlayer.swift` и `SleepTimerSheet.swift`. **Не добавляй папку `BookVoice` внутрь уже существующей `BookVoice`.**

## Установка без Mac

1. Обнови файлы в корне репозитория GitHub и создай commit в `main`.
2. Открой **Actions → Build BookVoice for iPhone** и запусти сборку.
3. Скачай `BookVoice-unsigned-IPA` после успешной сборки.
4. Для установки на устройство потребуется подпись IPA, например через AltStore/SideStore. Бесплатный профиль Apple обычно требует обновления подписи каждые 7 дней.

В полном архиве есть `.github/workflows/ios.yml`. Если в репозитории уже существует `.github/workflows/main.yml` с таким же заданием, не добавляй второй файл workflow, иначе оба могут запускаться одновременно.

## Проверка

- Перейди в «Голос и чтение» → «Выбрать голос», попробуй RU/EN/HY и «Все».
- Проверь каталог после установки дополнительного системного голоса.
- Прослушай примеры и проверь, что выбор сохраняется после перезапуска.
- Открой многопараграфный PDF: сравни обычный режим и «Перед сном».
- Заблокируй экран при чтении: проверь кнопку паузы и переход между страницами.

Проверен синтаксис всех Swift-файлов парсером Swift в Linux, валидность `project.yml` и структура ZIP. Полная компиляция с iOS SDK и воспроизведение на реальном устройстве не проверены; результат GitHub Actions потребуется подтвердить отдельно.
